# Internationalization

Locales: `en`, `hi`, `mr` in `apps/web/src/i18n/`.

- Never hardcode user-facing copy in components; use `t('key')`.
- Persist `users.locale` via `PATCH /users/me`.
- Settings screen switches language immediately.
- Tournament custom rules copy lives under `tournamentRules.*` (en / hi / mr).
- Use CSS logical properties (`margin-inline`, `inset-inline-start`) so RTL can be added later without rewriting layout.
